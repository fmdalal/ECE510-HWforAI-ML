# M4 — Hardware Accelerator: MHSA 9-Chiplet BF16 Systolic Array


**Target kernel:** Multi-Head Self-Attention (Conformer, github.com/sooftware/conformer)  
**Simulation:** QuestaSim 2021.3_1, mo.ece.pdx.edu, Jun 06 2026 — PASS, 0/1,024 mismatches  
**Synthesis:** Cadence Genus 19.12-s121_1, GPDK045 typical.lib, TILE_DIM=8

---

## File Catalogue

One line per file: relative path · description · checklist item / report section it supports.

### RTL Source (`rtl/`)

| File | Description | Supports |
|------|-------------|---------|
| `rtl/top.sv` | Top-level module. Instantiates axi_if and compute_core. Three clock domains: clk_axi 250 MHz, clk_core 1 GHz, clk_link 2 GHz. CDC via 2-FF synchronisers. | Design Justification Section 4 (Architecture); Verification M4 |
| `rtl/compute_core.sv` | 9-chiplet orchestration. Instantiates Chiplet 0, Chiplets 1–8 (head_gen), Chiplet 9, UCIe links, and direct tile mux arbiter. Drives cfg_start_core, busy_r, sts_done_core. | Design Justification  Section 4 (Dataflow); Verification M4 |
| `rtl/interface.sv` | AXI4-Lite CSR block (18 registers: CTRL, STATUS, SEQ_LEN, WEIGHT_ADDR, PERF_CYCLE, WDT, …), axis_input_fifo 256-beat, axis_output_fifo 256-beat. BEATS_PER_TILE = TILE_DIM²/32. | Design Justification Section 5 (Hardware Interface); Verification M2 |
| `rtl/chiplet_0_qkv_outproj.sv` | Stage 1 (QKV) and Stage 5 (OutProj). Three parallel systolic arrays sa_q/sa_k/sa_v. Weight-stationary FSM (W_IDLE→W_WQ→W_WK→W_WV→W_WO→W_DONE): weights loaded once, held while cfg_start asserted. sa_q reused for OutProj in cfg_mode=1. | Design Justification Section 4; Benchmark Section 1.1 (weight-stationary) |
| `rtl/chiplet_head.sv` | Stages 2 and 4 (QKᵀ and Prob×V). Parameterised by HEAD_ID=0..7. Output-stationary PEs; a_tile[TILE][TILE], b_tile[TILE][TILE] — no batch axis. | Design Justification Section 4; Benchmark  1.1 (B=1 RTL confirmation) |
| `rtl/chiplet_9_softmax.sv` | Stage 3 (softmax). Eight parallel softmax_pipe instances. LUT-based bf16_exp, FP32 sum reduction tree, Newton-Raphson reciprocal (2 iterations). | Design Justification Section 3 (Precision); Verification M2 |
| `rtl/fp32_arith.sv` | FP32 arithmetic primitives: fp32_mul, fp32_add (combinational), fp32_add_pip (2-stage pipelined — timing closure iteration 1). Contains systolic_array module: TILE×TILE PEs, output-stationary. Wave-front latency = K + 2(TILE−1) + 1 cycles. | Design Justification Section 4, Section 7 (Timing closure); Benchmark Section 5 (gap analysis) |
| `rtl/bf16_exp.sv` | LUT-based BF16 exponential. Multiplies by LOG2E_Q14, extracts integer k and fractional f_bits, looks up 128-entry lut_pos/lut_neg table, reconstructs 2^k × 2^f. Error ≤ 2⁻⁷. | Design Justification Section 3 (Precision) |
| `rtl/ucie_link.sv` | UCIe 1.0 FDI interface. ucie_tx and ucie_rx modules. 512-bit bump bus @2 GHz. Flit payload = 29 BF16 words; ceil(TILE²/29) flits per tile (36 flits = 18 ns at TILE=32). CRC-8 per flit. | Design Justification Section 5 (Hardware Interface) |
